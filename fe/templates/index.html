1. Enrichment

Thêm context và metadata vào chunks để improve retrieval quality.

Techniques:

  • Summary - tóm tắt chunk
  • HyQA - hypothesis questions
  • Contextual - mô tả vị trí chunk
  • Metadata - trích xuất metadata

2. Chunking

Chia document thành chunks nhỏ để retrieval.

Strategies:

  • Semantic - nhóm câu theo similarity
  • Hierarchical - parent/child chunks
  • Structure-aware - giữ cấu trúc markdown

3. Hybrid Search

Kết hợp BM25 (keyword) + Dense (semantic) + RRF.

Score calculation:

RRF(d) = Σ 1/(k + rank)

k = 60 (default)

4. Reranking

Sử dụng cross-encoder để rerank top-k results.

Model:

BAAI/bge-reranker-v2-m3

Input: (query, document) pairs

5. LLM Answer

Generate câu trả lời từ context + question.

Model:

GPT-4o-mini

Temperature: 0.3 (low for factual)
