# Visual QA Rubric

Score each dimension 0–5.

## Product fit
5 = composition, density, controls, and content clearly fit the product.
0 = could be any generic template.

## Hierarchy
5 = scan order and primary action are immediate.
0 = all elements compete or nothing is emphasized.

## Typography
5 = deliberate scale, readable body, strong numeric/text rhythm.
0 = random sizes/weights or unreadable hierarchy.

## Spacing/alignment
5 = repeatable rhythm and strong optical alignment.
0 = arbitrary gaps/padding and visible misalignment.

## Density
5 = amount of information matches the task.
0 = unusably cramped or wastefully sparse.

## Component consistency
5 = controls/surfaces follow a coherent system.
0 = each section appears independently styled.

## Content realism
5 = layout survives domain-realistic data and states.
0 = only placeholder happy-path data works.

## Responsive
5 = interactions are intentionally recomposed.
0 = broken overflow or essential features disappear.

## Accessibility
5 = keyboard/focus/labels/contrast/motion basics are solid.
0 = critical interactions are inaccessible.

## Motion
5 = purposeful, restrained, smooth, accessible.
0 = distracting, sluggish, or absent where continuity is needed.

## AI-likeness
5 = feels product-specific and intentionally designed.
3 = competent but generic.
0 = obvious generated SaaS template.

## Severity heuristic

Any 0–1 in:
- hierarchy
- responsive
- accessibility
- product fit

is at least P1 and may be P0 depending on impact.
