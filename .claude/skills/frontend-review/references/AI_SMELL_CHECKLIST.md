# AI Smell Checklist

Mark a smell only when it is unjustified for the product.

## Visual

- [ ] purple/blue gradient brand by default
- [ ] random glow / aurora
- [ ] glassmorphism
- [ ] excessive rounded cards
- [ ] nested cards
- [ ] excessive pill controls
- [ ] uniform card grid for unrelated content
- [ ] decorative icon circles everywhere
- [ ] giant page headings in an app
- [ ] too much empty space in operational UI
- [ ] every section is centered
- [ ] arbitrary shadows

## Structural

- [ ] dashboard = only KPI cards
- [ ] landing = hero + bento + testimonials + CTA with no product-specific story
- [ ] chat = marketing hero above conversation
- [ ] admin = records converted to huge cards
- [ ] mobile = desktop with hidden sidebar and nothing else adapted

## Content

- [ ] placeholder names dominate
- [ ] fake perfectly rounded metrics
- [ ] unrealistic short labels
- [ ] generic "AI-powered" copy
- [ ] no edge cases

## Interaction

- [ ] every card scales on hover
- [ ] every section fades up
- [ ] animated delays make actions feel slower
- [ ] essential controls appear only on hover
- [ ] no visible focus
- [ ] missing loading/error/empty states

## Product specificity test

Ask:

> Which design decisions on this screen would be different if the product were a completely different SaaS?

If the answer is "almost none", the UI is too generic.
