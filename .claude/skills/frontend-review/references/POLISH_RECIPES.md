# High-Impact Polish Recipes

Use only after product fit and hierarchy are correct.

## Screen feels flat
Do:
- strengthen primary text/action contrast,
- tighten weak groupings,
- improve type scale,
- reduce unnecessary borders.

Do not immediately add gradient/shadow.

## Screen feels busy
Do:
- remove competing accents,
- reduce repeated containers,
- group secondary actions,
- simplify labels,
- reduce icon decoration.

## Screen feels amateur
Check:
- inconsistent control heights,
- inconsistent radius,
- random font weights,
- misaligned baselines,
- weak empty states,
- unrealistic copy/data.

## Dashboard feels generic
Do:
- identify the actual decision the dashboard supports,
- promote one decision signal,
- combine secondary metrics,
- add comparison/context,
- reduce equal-weight KPI cards.

## Chat feels generic
Do:
- improve message rhythm,
- tune content width,
- make composer feel anchored,
- improve source/status placement,
- reduce chrome around messages.

## Landing feels templated
Do:
- rewrite section order around product narrative,
- use product screenshots/demo as evidence,
- remove generic feature grid,
- make art direction consistent with domain imagery/content.
