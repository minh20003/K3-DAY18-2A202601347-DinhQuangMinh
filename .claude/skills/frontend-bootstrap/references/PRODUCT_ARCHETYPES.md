# Product Archetypes

Use these as starting points, not rigid templates.

## Chat / Messaging

Priority:
1. conversation readability
2. composer
3. current context
4. message actions
5. presence/status

Visual guidance:
- medium density
- quiet chrome
- strong text legibility
- reduce cards
- composer should feel anchored
- secondary actions should be contextual

Avoid:
- dashboard KPI cards above the conversation
- oversized page headings
- visual effects competing with messages

## RAG / AI Assistant

Priority:
1. question/answer flow
2. citations/sources
3. reasoning/status when appropriate
4. conversation history
5. knowledge scope/filter

Useful patterns:
- split source panel
- inline citations
- expandable evidence
- explicit loading/retrieval state
- empty starter prompts only when helpful

Avoid:
- giant marketing hero inside the working product
- decorative AI sparkles everywhere
- hiding source provenance

## Dashboard / Analytics

Priority:
1. decision signal
2. trend/context
3. comparison
4. drill-down
5. operational detail

Visual guidance:
- medium to high density
- restrained surfaces
- chart/table alignment
- meaningful semantic color
- compact filters

Avoid:
- 8 equal KPI cards
- rainbow charts
- huge whitespace
- chart decoration without analytical value

## Admin / Operations

Priority:
1. scan
2. filter
3. select
4. edit
5. status

Visual guidance:
- high information density
- clear table/list system
- consistent row actions
- robust empty/error/loading states
- keyboard-friendly controls

Avoid:
- marketing spacing
- giant cards for each record
- hidden critical actions for aesthetic minimalism

## SaaS Productivity

Priority:
1. current work object
2. primary action
3. navigation
4. contextual controls
5. collaboration/status

Visual guidance:
- calm
- precise
- medium-high density
- low ornament
- contextual actions
- keyboard shortcuts where useful

## Landing Page

Priority:
1. value proposition
2. evidence
3. product understanding
4. differentiation
5. conversion

Visual guidance:
- expressive typography allowed
- image/product-demo led
- stronger art direction
- motion can be more cinematic
- maintain scannable section narrative

Avoid:
- generic "AI-powered future" copy
- meaningless bento grid
- 12 feature sections
- decorative animation that delays comprehension

## Homepage / Discovery

Priority:
1. orientation
2. discovery
3. key categories/content
4. relevance
5. next action

Visual guidance depends heavily on product:
- marketplace = browsing and trust
- media = editorial hierarchy
- enterprise = task entry points
- consumer app = personalization and discovery

Avoid treating every homepage as a landing page.

## E-commerce / Marketplace

Priority:
1. browse/find
2. evaluate
3. compare
4. trust
5. purchase/contact

Stress test:
- long product names
- sale states
- unavailable states
- image ratios
- filters
- variant counts

## Developer Tool

Priority:
1. code/config clarity
2. status
3. navigation
4. logs/output
5. command actions

Visual guidance:
- precise
- compact
- strong monospace support
- subtle semantic states
- minimal ornament
