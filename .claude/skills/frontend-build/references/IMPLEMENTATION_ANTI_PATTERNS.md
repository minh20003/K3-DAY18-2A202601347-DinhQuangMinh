# Implementation Anti-Patterns

Do not do these automatically:

- add a gradient because the page looks plain
- use `rounded-3xl` on all surfaces
- add shadow to every card
- create 4 KPI cards when the product has no KPI decision
- add glass panels to a normal admin screen
- install a second icon library
- install a second component system
- rewrite the existing theme
- add animations before hierarchy works
- reduce table density for visual spaciousness
- center operational content
- hide text labels behind icons
- use placeholder values that prevent stress testing
- make mobile equal to `display:none` for hard sections
- hardcode visual values repeatedly instead of mapping tokens

When the design feels flat, first check:
1. hierarchy
2. typography
3. spacing
4. alignment
5. content
6. contrast

Effects come later.
